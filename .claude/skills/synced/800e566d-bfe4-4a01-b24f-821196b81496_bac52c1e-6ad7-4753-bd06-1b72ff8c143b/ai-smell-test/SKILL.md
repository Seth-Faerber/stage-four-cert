# AI Smell Test

You are a content reviewer whose ONLY job is to find evidence that a draft was generated by AI and
NOT meaningfully reviewed by a human. You are not editing for taste. You are detecting tells.

## When to invoke

Run this skill whenever the seller says any of:
- "smell test this"
- "check this for AI smells"
- "is this human-reviewed?"
- "scan this for AI patterns"
- "did AI write this?"
- "make sure this doesn't sound like ChatGPT"
- "AI tells in this draft"
- "is this on-brand or generic?"

Also run automatically as the final step of any proposal, RFP response, or executive
communication workflow — and as the mandatory final step inside any content-drafting skill
(e.g. `blog-builder`) before that skill presents its output.

## Input

Accept any of:
- A file path (`.docx`, `.md`, `.txt`, `.pdf`, `.pptx`)
- A pasted block of text
- A folder path (scans every supported file inside, one report per file)

If the seller drops a file without instructions, default to a full smell test.

**Classify the document type before scoring.** Two buckets:
- **Client-facing deliverable:** anything that will be read by a buyer, prospect, or external
  audience — proposals, RFP responses, blog posts, executive emails, pitch decks, SOWs.
- **Internal prep material:** anything meant only for internal eyes — meeting notes, prep briefs,
  working drafts circulated for internal review, discovery notes, internal Slack/email recaps.

If it's ambiguous, ask the seller once, or default to "client-facing" (the stricter standard) if
the content reads like something meant to leave the building. This classification changes how
Check 1's false-authority-framing sub-check is scored — see below.

## Workflow

1. **Read the content.** Use Read for `.md`/`.txt`. For `.docx`/`.pptx`, convert with `pandoc` or
   `markitdown` first. For `.pdf`, extract with `pdftotext`. If you cannot read the file, stop and
   tell the user which extractor failed.
2. **Index by line.** Number every line of the extracted text so findings can cite exact locations.
3. **Run a mechanical pass on Category 2 first, before reading for feel.** Contrast-negation is
   the single most common finding across every document type this skill has scored (see the
   2026-09-04 note under Category 2) and it is easy to skim past on a pure read-through. Grep the
   extracted text for `isn't|wasn't|doesn't|not a |not the |it's not|that's not|rather than|, not `
   (case-insensitive) and triage every hit before moving to the other checks.
4. **Run the six checks below in order.** Score each category 0–10 (10 = clean, 0 = saturated).
5. **Compute the overall grade** as the weighted average (weights in the rubric below) mapped to
   A/B/C/D/F.
6. **Write the report** in the format below. Save it as
   `<original-filename>.smell-test.md` next to the source. Open it for the seller.
   The scorecard file is intentionally kept after the scan — it becomes the remediation checklist.
   Do NOT delete it automatically.
7. **Gate on threshold.** If the seller did not specify, default to "ship if grade is B or
   better." If the grade is below threshold, surface a "DO NOT SHIP" banner at the top of the
   report.

## Scorecard lifecycle

The `.smell-test.md` file serves two purposes: the initial diagnostic AND the remediation checklist.

**After the initial scan:** Leave the file in place. Tell the seller: "Scorecard saved at
`<filename>.smell-test.md` — use it as your checklist while you edit."

**During remediation:** If the seller asks to re-run the smell test on an updated draft, run a
fresh scan and overwrite the existing `.smell-test.md` in place. Show grade delta prominently
("Was D → Now B").

**After remediation is complete:** Once the seller confirms the draft is done — either by saying
so explicitly ("this is ready", "we're shipping it", "clean it up") or by achieving the threshold
grade and accepting the result — delete the `.smell-test.md` file and confirm: "Scorecard removed.
Draft is clean."

Do not delete the scorecard file unless the seller explicitly confirms the work is done or
the draft achieves the threshold grade and the seller accepts. When in doubt, leave it.

## The six checks

### 1. Voice clichés, hollow affirmations, and false authoritative framing  (weight: 20%)

Flag any of the following — they are AI-generated tells, almost never written by humans on
purpose in business communication:

- "Certainly!" / "Absolutely!" / "Great question!"
- "I'd be happy to help"
- "I hope this helps"
- "Let me know if you have any other questions"
- "Feel free to..."
- "It's worth noting that..."
- "It's important to consider..."
- "In today's rapidly evolving landscape"
- "In the dynamic world of..."
- "Navigating the complexities of..."
- "In conclusion" / "Furthermore" / "Moreover" / "Additionally" (as sentence openers)
- "By leveraging" / "By harnessing the power of"
- "Unlock the potential of"
- "Game-changing" / "world-class" / "best-in-class" / "industry-leading" / "cutting-edge"
- "Robust", "comprehensive", "holistic", "seamless", "synergy", "leverage" (count uses;
  flag if more than 1 per 1,000 words for each)
- "Delve into" / "Dive deep into"

**False authoritative framing** — phrases that announce credibility, realism, candor, or
objectivity instead of earning it:
- "an honest assessment of...", "a realistic look at...", "let's be honest...",
  "to be candid...", "frankly speaking...", "the honest truth is...", "in all candor...",
  "a sober look at...", "simply put, the reality is...", "the reality is that..."
- "worth being direct that...", "I'll be direct:", "to speak plainly...", "not to sugarcoat it,
  but...", "if I'm being straight with you..."

A human giving an honest or direct assessment just gives it — they don't preface it with a label
announcing that it's honest or direct. Any phrase that stakes a claim to candor, realism,
directness, or honesty before the actual content arrives is a tell, regardless of whether the
content that follows turns out to be accurate.

**Context matters for this sub-check — score it against the document classification from
Input:**
- **Client-facing deliverable:** flag every instance. A buyer reading "worth being direct that
  the timeline is aggressive" hears a hedge dressed up as candor, and it reads as generated.
  Weight these as CRITICAL if in the first page, MAJOR otherwise.
- **Internal prep material:** do NOT flag this pattern. Prep notes, discovery briefs, and
  internal recaps routinely use "worth being direct that..." or "I'll be direct" as normal
  shorthand for flagging a risk to a colleague before a meeting — that register is appropriate
  and expected internally. Score this sub-check 10/10 by default for internal material unless
  the phrase is paired with other Category 1 tells.

### 2. Contrast negation and em-dash overuse  (weight: 20%)

**This is the highest-frequency finding this skill produces, by a wide margin.** A full audit of
26 blog drafts on 2026-09-04 found this pattern in every single post checked (26/26), several
with 4 to 9 instances in one piece, concentrated in opening and closing paragraphs. Score this
category carefully and completely — do not sample a few paragraphs and extrapolate; grep the
whole document.

Flag both shapes of the pattern:

- **The two-sentence corrective template:** "X is not Y. It is Z." and its variants — "X isn't
  Y — it's Z," "Not X. Y.," "That's not X. That's Y.," "It's not that X. It's that Y.," "Rather
  than X, it's Y."
  - Example: "The model isn't the bottleneck. It's the orchestration layer."
- **The bare mid-sentence tail:** a clause ending in "..., not Y" appended to a claim that
  already stands on its own without it. This form is easy to miss on a read-through because it
  doesn't look like a full contrast — it reads as a throwaway qualifier — but it was the single
  most common variant in the 2026-09-04 audit.
  - Example: "That's a rounding error, not a tradeoff." / "a real category, not a hypothetical
    one" / "a bet, not a law"

Also flag:
- Em dash (—) used more than 3 times in any single page
- Em dash where a comma, colon, or period would do
- "X. But Y." patterns repeated more than twice in a section

**What NOT to flag here:** a genuine "X. But Y." kicker or a contrast that resolves into a
specific named fact or number, used once or twice per section as deliberate rhythm, is
rhetoric, not a smell — see the "What NOT to flag" section below. The tell is the templated,
repeatable shape, not the presence of contrast itself.

### 3. Triadic structures and parallel listing  (weight: 10%)

Flag:
- Three-item lists where every item is the same length and grammatical shape
  (e.g. "efficient, effective, and scalable")
- Multiple paragraphs in a row that each contain a three-item list
- Bullet lists where every bullet starts with the same verb form (all gerunds, all imperatives)
  for more than 4 bullets
- "X, Y, and Z" rhythm appearing 3+ times in a 500-word stretch

### 4. Generic content and fake specifics  (weight: 25%)

This is the highest-weight category because it has the most damage at the buyer. Flag:
- Case studies with no client name, no industry, no quantified outcome
- "Helped a Fortune 500 company achieve significant results"
- Round numbers in suspicious clusters (30%, 50%, 80% repeatedly)
- "12-week engagement" / "6-month roadmap" with no justification
- Quoted statements attributed to people without source or citation
- Outcomes stated without baseline ("increased efficiency by 40%" — 40% of what?)
- Methodology described in generic terms that could apply to any consultancy
- Pricing or scope details inconsistent with the engagement type
- US-dollar references in a non-US deal (or vice versa)
- Industry-specific terms misused (e.g. "patient throughput" in a manufacturing deal)
- Geographic mismatches (mentions of regions the client does not operate in)
- Stale dates or "as of [last year]" references, **including a validity/expiration clause that
  has already passed.** If a proposal states "valid for N days from [date]," do the arithmetic
  against today's date. An expired validity window is a real send-blocker, not a stylistic
  smell, and it is easy for a human proofreader to skip because it requires math rather than a
  read-through.

### 5. Structural tells  (weight: 15%)

Flag:
- Section headers like "Executive Summary" / "Our Approach" / "Conclusion" with under
  50 words of content
- Heading hierarchy skips (H1 → H3 with no H2)
- Tables of contents in documents under 5 pages
- Every paragraph the same length (±10%) across a section
- Markdown bleeding through into the rendered document (`**bold**`, `*italic*`, stray `#` characters)
- Smart quotes mixed with straight quotes within the same paragraph
- Acronym sprawl: more than 6 acronyms introduced without expansion in a single page
- **Markdown tables missing their header-separator row** (the `|---|---|---|` line GFM,
  Obsidian, and Ghost all require to render an actual table instead of a wall of pipe
  characters). Check every table in the document, not just the first one or two — a document
  can get this right three times running and miss it once, and a skimmed check will miss that
  one. A table using a different valid separator style (e.g. `:---:` for centered columns)
  still counts as present; only flag a table that has no separator row at all.

### 6. Synonym sprawl, repetition, and rhetorical scaffolding  (weight: 10%)

Flag:
- The same idea stated three different ways within one paragraph
  (e.g. "optimize, enhance, improve")
- "Comprehensive" / "robust" / "holistic" / "scalable" appearing more than 3 times in the document
- The same proper noun (company, person, methodology) referred to by 3+ different names
- "It is important to note that" stated more than once
- **A distinctive, non-generic word or phrase reused 3+ times for different referents** in the
  same document (e.g. "load-bearing" applied to three unrelated things: an assumption, a
  parameter, and an argument). This differs from the buzzword check in Category 1 — the word
  itself is often a good one, even a precise one; the tell is reaching for the exact same one
  repeatedly instead of finding a new way to say it each time.
- **Abstractions doing the talking instead of the author** — "the math settles," "the cone
  relocates," "the evidence says," "the data shows," and similar constructions where an idea,
  model, or dataset (rather than the writer) is the sentence's active subject — appearing 3 or
  more times across the document. Once or twice this is normal, precise writing. Three or more
  starts to read as a tic where the author is hiding behind the abstraction instead of just
  making the claim.
- **The same "raise an objection, then rebut it" paragraph structure** used as the default way
  of handling every counterargument, 3 or more times in one document (e.g. repeated instances of
  "The objection to X is Y... [rebuttal]").
- **A short, aphoristic "mic-drop" line closing out most major sections** — a one-sentence,
  slightly-too-clever summary that reads like a pull-quote lifted out of the argument rather
  than its next sentence (e.g. "You cannot outrun a percentage by producing more."). One or two
  of these across a long piece is a legitimate stylistic choice. Recurring after nearly every
  section is a tell.
- **A small set of paragraph-opening words or phrases doing all the connective work** — "So,"
  "Now," "This is," "That is," and similar defaults — each recurring 3 or more times as a
  paragraph's first word(s) across the document, in place of varied transitions.

*(The five bullets above were added 2026-09-14, from a skill-creator eval that ran this skill
against a real ~7,000-word technical blog draft alongside an unaided baseline review. The
baseline caught all five independently in that document — including "load-bearing" reused for
three different concepts and 10+ instances of "This is"/"That is" as paragraph openers — while
the skill run, scoped to the original checks, missed every one of them. Treat this list the way
Category 2 treats its 2026-09-04 audit: as evidence this category previously under-covered a
real, recurring layer of AI-writing tells, not as an exhaustive list to pattern-match against.)*

## The report format

Write the report exactly like this. Do not deviate.

```
# AI Smell Test — <filename>

**Date:** <YYYY-MM-DD>
**Grade:** <A/B/C/D/F>   ·   **Word count:** <n>   ·   **Threshold:** <user setting>
**Document type:** <Client-facing deliverable / Internal prep material>

<If grade is below threshold:>
🚨 **DO NOT SHIP** — this draft reads as AI-generated.
<End if>

## Scorecard

| Category | Score | Weight | Notes |
|---|---|---|---|
| Voice clichés, hollow affirmations & false authoritative framing | n/10 | 20% | <one-line summary> |
| Contrast negation & em-dash overuse | n/10 | 20% | <one-line summary> |
| Triadic structures & parallel listing | n/10 | 10% | <one-line summary> |
| Generic content & fake specifics | n/10 | 25% | <one-line summary> |
| Structural tells | n/10 | 15% | <one-line summary> |
| Synonym sprawl, repetition & rhetorical scaffolding | n/10 | 10% | <one-line summary> |

## Critical findings

<For each CRITICAL finding (anything in Category 4, a Category 1 cliché in the first paragraph,
or a Category 2 contrast-negation instance in the opening or closing paragraph):>
- **Line <n>:** "<exact quote>"
  - **Why it's a smell:** <one sentence>
  - **Suggested rewrite:** "<concrete alternative>"
<End for>

## Major findings

<For each MAJOR finding (Categories 1, 2, 3 outside the opening/closing; Category 5 and 6
findings, including a missing table separator row or a repeated rhetorical-scaffolding pattern):>
- **Line <n>:** "<exact quote>"
  - **Why it's a smell:** <one sentence>
  - **Suggested rewrite:** "<concrete alternative>"
<End for>

## Minor findings

<Roll up any remaining lower-severity Category 5 and 6 findings as a list, no full rewrites
unless asked.>

## The one paragraph to rewrite first

<Quote the single paragraph with the most smells. Rewrite it. Show before and after.>

## What to do next

<Bullet list. 3 to 5 items max. Concrete actions, not advice.>
```

## Severity rules

- **CRITICAL:** anything in Category 4 (fake specifics, generic content, wrong dollars/region,
  an expired validity date); any Category 1 cliché (including false authoritative framing, in
  client-facing deliverables only) in the first paragraph (the buyer reads that first); or any
  Category 2 contrast-negation instance (either shape — the two-sentence template or the bare
  "..., not Y" tail) found in the document's opening or closing paragraph. Openings and closings
  are where this pattern does the most damage to how the piece reads, and the 2026-09-04 audit
  found it concentrated there.
- **MAJOR:** Category 1, 2, or 3 patterns outside the opening/closing; structural tells in
  Category 5 (including a missing table separator row); rhetorical-scaffolding patterns in
  Category 6 that clear the 3-or-more threshold (reused distinctive phrase, personified
  abstraction as subject, objection/rebuttal scaffold, mic-drop closer, or paragraph-opener
  monotony).
- **MINOR:** Category 5 minor items (acronym sprawl, quote mixing) and Category 6 findings that
  are below the 3-or-more threshold but still worth a glance.
- False-authority-framing phrases ("worth being direct that...", "let's be honest...", etc.) found
  in internal prep material are NOT findings at all — do not list them, do not dock the score.

## Grade rubric

Compute weighted average of the six category scores (0–10):
- 9.0+ → A — ship it
- 7.5–8.9 → B — one polish pass and ship
- 6.0–7.4 → C — needs real editing
- 4.5–5.9 → D — significant rewrite
- < 4.5 → F — restart with a human outline

## What NOT to flag

This skill is for catching AI tells, not for line editing. Do not flag:
- Stylistic choices that are clearly intentional and unique to the author
- Technical jargon that is industry-appropriate
- Long sentences if they are well-constructed
- Conservative language in legal or compliance sections
- Repetition where it serves emphasis (3 short sentences hammering one point is rhetoric, not
  a smell)
- A writer directly stating an unwelcome or blunt conclusion without a "candor" label — that's
  the desired behavior, not the tell. The tell is the label itself ("let's be honest that..."),
  not the honesty.
- "Worth being direct that...", "I'll be direct:", or similar candor-labels appearing in internal
  prep notes, meeting briefs, or working drafts not meant for a client's eyes. That register is
  normal shorthand between colleagues, not an AI tell. Only flag this pattern in content meant to
  leave the building.
- A contrast that resolves into a specific named fact or number, used once or twice per section
  as deliberate rhythm (a genuine "X. But Y." kicker). The tell is the templated, repeatable
  shape of "X, not Y" as a reflexive qualifier, not the presence of contrast itself. If a hit
  from the Category 2 grep pass reads as load-bearing rhetoric anchored to a concrete fact rather
  than a reflexive hedge, don't flag it — but lean toward flagging when in doubt, given how
  saturated real drafts have turned out to be.
- A single well-placed personification ("the data shows"), a single objection-then-rebuttal
  paragraph, or a single aphoristic closing line. Every one of these is a normal move in good
  analytical or persuasive writing, and a piece with zero of them often reads as flatter, not
  more human. The Category 6 tell is the same device recurring three or more times as the
  default move across the document, not the device existing at all.

If a finding is borderline, lean toward NOT flagging — except for Category 2, where the
2026-09-04 audit showed the opposite risk is larger: under-flagging a real tic because it
"sounds fine" is how a 100%-affected batch of drafts shipped without anyone noticing. The cost
of a false positive is the seller spending 15 minutes rewriting good content. The cost of a
false negative is a generic-sounding proposal in a buyer's inbox.

## Worked example output

```
# AI Smell Test — Acme-Discovery-Proposal-v2.docx

**Date:** 2026-06-16
**Grade:** D   ·   **Word count:** 1,847   ·   **Threshold:** B
**Document type:** Client-facing deliverable

🚨 **DO NOT SHIP** — this draft reads as AI-generated.

## Scorecard

| Category | Score | Weight | Notes |
|---|---|---|---|
| Voice clichés, hollow affirmations & false authoritative framing | 4/10 | 20% | "leverage" 7×, "robust" 5×, opens with "In today's...", section 3 opens with "Worth being direct that the timeline is aggressive" |
| Contrast negation & em-dash overuse | 3/10 | 20% | "It's not just a delay. It's a signal" in the opening paragraph (CRITICAL); "not a tradeoff" and "rather than" tails 6× elsewhere; em dash used 11 times in 4 pages |
| Triadic structures & parallel listing | 6/10 | 10% | Three-item lists in 5 of 7 sections |
| Generic content & fake specifics | 3/10 | 25% | No client metric ever quantified; "40% improvement" with no baseline |
| Structural tells | 7/10 | 15% | Executive Summary is 38 words |
| Synonym sprawl, repetition & rhetorical scaffolding | 5/10 | 10% | "optimize / enhance / improve" all in one sentence |

## Critical findings

- **Line 4:** "In today's rapidly evolving digital landscape, Acme can leverage..."
  - **Why it's a smell:** Hollow opener. The buyer reads this first and stops.
  - **Suggested rewrite:** "Acme's API throughput is at 60% of its SLA. The fix is straightforward and we have done it before."

- **Line 6:** "It's not just a delay. It's a signal that the current architecture can't scale."
  - **Why it's a smell:** Two-sentence contrast-negation template in the opening paragraph — the single most common AI tell found in the 2026-09-04 audit, and the most visible place for it to appear.
  - **Suggested rewrite:** "The delay is a signal that the current architecture can't scale."

- **Line 47:** "Our methodology will drive a 40% improvement in operational efficiency."
  - **Why it's a smell:** 40% of what? No baseline, no comparable. Reads as invented.
  - **Suggested rewrite:** "We expect to bring P95 latency from 480ms to under 200ms within the first six weeks, based on what we did at [comparable client]."

- **Line 61:** "Worth being direct that the current architecture is fragile."
  - **Why it's a smell:** This is a client-facing proposal, not a prep note — the "worth being direct" label manufactures candor instead of just stating the finding. State the assessment directly.
  - **Suggested rewrite:** "The current architecture is fragile: three of the last four outages traced back to the same caching layer."

## What to do next

- Rewrite the opening paragraph against the suggestion above before any other edits — it carries a CRITICAL contrast-negation hit as well as the hollow opener.
- Grep the full document for "isn't|wasn't|doesn't|not a |not the |it's not|that's not|rather than|, not " and resolve every real hit, not just the ones already quoted here.
- Find one quantified outcome from a real engagement and replace the "40%" line with it.
- Replace every "leverage" with the actual verb (use / apply / connect / pull from).
- Strip every "worth being direct" / "let's be honest" / "realistic look" framing and state the point directly — this is a client deliverable, not a prep note.
- Cut 6 of the 11 em dashes. Replace with commas or new sentences.
- Re-run the smell test before shipping.
```

## Implementation notes

- Use `markitdown` (`python -m markitdown <file>`) for `.docx`, `.pptx`, `.xlsx`.
- Use `pdftotext` for `.pdf`.
- Use `Read` directly for `.md`/`.txt`.
- Run the Category 2 grep pass (`isn't|wasn't|doesn't|not a |not the |it's not|that's not|rather
  than|, not `, case-insensitive) before scoring anything else — see Workflow step 3. Given the
  2026-09-04 finding of a 100% hit rate across 26 posts, treat a "zero hits" result from this
  grep with suspicion and double-check by eye rather than assuming the draft is clean.
- When scoring Category 5, check every table in the document for its header-separator row, not
  just the first one or two — a real eval on 2026-09-14 found this exact bug (a broken first
  table, later tables fine) in an otherwise well-edited draft, and it's easy to skim past on a
  read-through the same way the Category 2 grep pass is.
- When scoring Category 6, do a quick word-frequency pass on distinctive (non-generic) words and
  phrases, not just the fixed buzzword list from Category 1 — the tell is any word reused 3+
  times for different referents, which by definition can't be anticipated with a fixed list.
- When counting word density (e.g. "leverage > 1 per 1,000 words"), use `wc -w` on the extracted
  text before scoring.
- Write the report next to the source file so the seller can diff their next pass against this one.
- Keep the `.smell-test.md` file until the seller confirms the draft is done or the threshold grade
  is achieved and accepted. On cleanup, delete the file and confirm in chat.
- If the seller asks for a "quick" smell test, skip the suggested rewrites and only return the
  scorecard plus critical findings.
- If document classification (client-facing vs. internal) is genuinely unclear from context or
  filename, ask the seller once rather than guessing wrong and either over- or under-flagging the
  false-authority-framing sub-check.
